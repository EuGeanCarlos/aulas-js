# Aulas de JavaScript

Coleção de exercícios de operadores, atribuições, strings, condicionais, repetições, arrays e DOM, organizada em pastas independentes.

## Tecnologias

- HTML
- JavaScript

## Funcionalidades e utilização

Abra o index.html da aula desejada; alguns exercícios apresentam a saída no console do navegador. A aula de arrays não possui script versionado.

## Como executar

```bash
git clone https://github.com/EuGeanCarlos/aulas-js.git
cd aulas-js
python -m http.server 8000 --directory "."
```

Requer Python 3 para o servidor local. Abra http://localhost:8000.
